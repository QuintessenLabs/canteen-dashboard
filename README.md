# Campus Canteen Dashboard

A PSDT prototype for checking seat availability on a campus canteen floor plan.

[Open the live dashboard](https://canteen.vinoushippo4.chatgpt.site)

Open `index.html` in a browser to run the demo locally. **Simulate camera update** changes the sample seat counts. **Camera assignments** shows which tables and standing stations are assigned to each camera.

The schematic CAD floor plan is included in DWG and DXF formats.
